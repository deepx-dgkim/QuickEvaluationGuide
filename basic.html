Hands-on: benchmark YOLO26n object detection end-to-end

실습으로 따라하기: YOLO26n 객체 검출 모델 처음부터 끝까지 benchmark

实战教程：从头到尾对 YOLO26n 目标检测模型进行端到端性能评测

ハンズオンチュートリアル：YOLO26n 物体検出モデルをエンドツーエンドで benchmark する

Thực hành: benchmark object detection YOLO26n từ đầu đến cuối

Instead of abstract commands, this guide follows one real model — DEEPX's YOLO26n object detector — from download, to a live NPU dashboard with dxtop, to maximum throughput, to a representative 30 fps deployment test, all the way to a real application and a real video pipeline. The results shown in this guide are reference measurements. Exact values may vary depending on the host system, software version, and system configuration.

추상적인 명령어 나열 대신, DEEPX의 YOLO26n 객체 검출 모델 하나를 기준으로 다운로드부터 dxtop 실시간 대시보드 확인, 최대 처리량 측정, 대표적인 30fps 테스트, 그리고 실제 애플리케이션·비디오 파이프라인 실행까지 끝까지 따라가 봅니다. 이 가이드에 나오는 결과는 참고용 측정치이며, 정확한 수치는 호스트 시스템, 소프트웨어 버전, 시스템 구성에 따라 달라질 수 있습니다.

本指南不罗列抽象的命令，而是以一个真实模型 —— DEEPX 的 YOLO26n 目标检测器 —— 为主线，从下载模型开始，到用 dxtop 查看实时 NPU 仪表盘，再到测试最大吞吐量，然后进行具有代表性的 30 fps 测试，最后延伸到真实应用和真实视频流水线。本指南中展示的结果均为 参考测量值，具体数值可能因主机系统、软件版本及系统配置的不同而有所差异。

本ガイドでは、抽象的なコマンドの羅列ではなく、1つの実際のモデル ——DEEPX の YOLO26n 物体検出器——を通して、ダウンロードから dxtop によるライブ NPU ダッシュボードの確認、最大スループットの計測、 代表的な 30 fps でのデプロイテスト、そして実際のアプリケーションと 実際のビデオパイプラインまでを一貫して解説します。本ガイドに示す結果は 参考測定値であり、実際の数値はホストシステム、ソフトウェアバージョン、 システム構成によって異なる場合があります。

Thay vì các lệnh trừu tượng, hướng dẫn này bám theo một model thực tế — bộ object detector YOLO26n của DEEPX — từ lúc tải về, đến dashboard NPU thời gian thực với dxtop, đến throughput tối đa, đến bài kiểm thử triển khai tiêu biểu ở 30 fps, và cuối cùng là một ứng dụng thực tế cùng một pipeline video thực tế. Các kết quả trong hướng dẫn này là số đo tham khảo. Giá trị cụ thể có thể thay đổi tùy theo host system, phiên bản phần mềm và cấu hình hệ thống.

1. Tải model dùng cho case study: YOLO26n

We'll use YOLO26n — DEEPX's compact "nano" object detector, 640×640 input — as the running example for the rest of this guide. It's also the model dx_stream's quick demo runs by default (Step 6), so every tool in this walkthrough — dxrun, dxtop, dx_app, and dx_stream — exercises the exact same model file end to end.

이 가이드 전체에서 실습 대상으로 사용할 모델은 YOLO26n (DEEPX의 경량 "nano" 객체 검출 모델, 640×640 입력)입니다. 이 모델은 dx_stream의 빠른 데모(6단계)가 기본으로 사용하는 모델이기도 해서, dxrun, dxtop, dx_app, dx_stream 이 가이드에 등장하는 모든 도구가 동일한 모델 파일 하나로 끝까지 이어집니다.
