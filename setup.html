1. DX-NPU driver

The kernel driver for the NPU — provides the dxrt_driver and dx_dma modules and the /dev/dxrt0 device node. It is built for the running kernel through DKMS (for a source build with the AllSuite installer, add --driver-source-build), and the modules load only after a reboot. DX-RT v3.5.0 requires driver v2.7.0 or newer.

NPU용 커널 드라이버로, dxrt_driver, dx_dma 모듈과 /dev/dxrt0 디바이스 노드를 제공합니다. DKMS로 현재 커널에 맞춰 빌드되며(AllSuite 설치 스크립트로 소스 빌드하려면 --driver-source-build 추가), 재부팅 후에 모듈이 로드됩니다. DX-RT v3.5.0에는 드라이버 v2.7.0 이상이 필요합니다.

NPU 内核驱动，提供 dxrt_driver 和 dx_dma 模块以及 /dev/dxrt0 设备节点。驱动通过 DKMS 针对当前运行的内核构建（使用 AllSuite 安装脚本进行源码构建时，添加 --driver-source-build），重启后模块才会加载。DX-RT v3.5.0 要求驱动 v2.7.0 或更高版本。

NPU 用のカーネルドライバです。dxrt_driver と dx_dma モジュール、および /dev/dxrt0 デバイスノードを提供します。DKMS により実行中のカーネル向けにビルドされ（AllSuite インストーラーでソースからビルドする場合は --driver-source-build を追加）、モジュールは再起動後に読み込まれます。DX-RT v3.5.0 にはドライバ v2.7.0 以降が必要です。

Kernel driver cho NPU, cung cấp các module dxrt_driver, dx_dma và device node /dev/dxrt0. Driver được build cho kernel đang chạy thông qua DKMS (để build từ source bằng trình cài đặt AllSuite, thêm --driver-source-build), và các module chỉ được nạp sau khi reboot. DX-RT v3.5.0 yêu cầu driver v2.7.0 trở lên.

cd dx-all-suite/dx-runtime

sudo apt install dxrt-driver-dkms

2. DX-RT

The DEEPX runtime and its CLI tools — dxcli, dxrun, dxtop, and dxbenchmark; the old names (dxrt-cli, run_model, parse_model) still work as aliases. The AllSuite installer also installs the same Debian package (libdxrt-bin) by default (use --rt-source-build for a source build). A matching Python dx_engine wheel ships in /usr/share/libdxrt-bin/python; install the one for your Python version into a virtual environment.

DEEPX 런타임과 CLI 도구입니다. dxcli, dxrun, dxtop, dxbenchmark가 포함되며, 예전 이름(dxrt-cli, run_model, parse_model)도 별칭으로 동작합니다. AllSuite 설치 스크립트도 기본적으로 같은 Debian 패키지(libdxrt-bin)를 설치합니다(소스 빌드는 --rt-source-build). 버전이 맞는 Python dx_engine wheel이 /usr/share/libdxrt-bin/python에 들어 있으므로, 사용하는 Python 버전용 wheel을 가상환경에 설치하세요.

DEEPX 运行时及其 CLI 工具：dxcli、dxrun、dxtop 和 dxbenchmark；旧名称（dxrt-cli、run_model、parse_model）仍可作为别名使用。AllSuite 安装脚本默认也安装同一个 Debian 软件包 libdxrt-bin（源码构建请使用 --rt-source-build）。对应版本的 Python dx_engine wheel 位于 /usr/share/libdxrt-bin/python，请将与当前 Python 版本匹配的 wheel 安装到虚拟环境中。

3. NPU F/W

The firmware running on the NPU module itself. Outdated firmware is a known cause of API compatibility problems — DX-RT v3.5.0 expects NPU FW v2.7.6 or newer. Firmware is not part of the APT packages, so with individual install you also update it separately as shown below.

NPU 모듈 자체에서 동작하는 펌웨어입니다. 오래된 펌웨어는 API 호환성 문제를 일으키는 것으로 알려져 있으며, DX-RT v3.5.0에는 NPU FW v2.7.6 이상이 필요합니다. 펌웨어는 APT 패키지에 포함되지 않으므로 개별 설치에서도 아래와 같이 따로 업데이트합니다.

NPU 模块上运行的固件。固件过旧已知会导致 API 兼容性问题，DX-RT v3.5.0 要求 NPU FW v2.7.6 或更高版本。固件不在 APT 软件包中，因此单独安装时也需按下文方式另行更新。

NPU モジュール上で動作するファームウェアです。ファームウェアが古いと API 互換性の問題が発生することが知られています。DX-RT v3.5.0 には NPU FW v2.7.6 以降が必要です。ファームウェアは APT パッケージに含まれないため、個別インストールの場合も以下のように別途更新します。

Firmware chạy trên chính module NPU. Firmware cũ là nguyên nhân đã biết gây lỗi tương thích API; DX-RT v3.5.0 yêu cầu NPU FW v2.7.6 trở lên. Firmware không có trong các gói APT, vì vậy khi cài riêng lẻ, bạn cũng cần cập nhật firmware riêng như hướng dẫn bên dưới.

cd dx-all-suite/dx-runtime
./install.sh --target=dx_fw
git clone https://github.com/DEEPX-AI/dx_fw

# path layout: dx_fw/<chip>/<fw version>/<form factor>/fw.bin
dxcli -g dx_fw/m1/2.7.6/mdot2/fw.bin   # check the image version first
sudo systemctl stop dxrt.service
dxcli -u dx_fw/m1/2.7.6/mdot2/fw.bin
sudo systemctl start dxrt.service

For a DX-M1M module use m1m instead of m1; the form-factor directory is mdot2 for an M.2 module and h1 for an H1 card. Pick the version directory that matches your DX-RT (DX-RT v3.5.0 → 2.7.6). Run the update with dxrt.service stopped, as above. If something goes wrong, see Basic → Step 0 troubleshooting for what to check.

DX-M1M 모듈은 m1 대신 m1m을 사용하고, 폼팩터 디렉터리는 M.2 모듈이면 mdot2, H1 카드면 h1입니다. 버전 디렉터리는 사용 중인 DX-RT에 맞는 것을 선택하세요(DX-RT v3.5.0 → 2.7.6). 위와 같이 dxrt.service를 정지한 상태에서 업데이트합니다. 문제가 생기면 Basic → 0단계 문제 해결에서 확인할 항목을 참고하세요.

DX-M1M 模块请用 m1m 代替 m1；外形规格目录：M.2 模块为 mdot2，H1 卡为 h1。请选择与 DX-RT 匹配的版本目录（DX-RT v3.5.0 → 2.7.6）。与上文相同，请在 dxrt.service 停止的状态下执行更新。如有问题，请参阅 Basic → Step 0 故障排查中的检查项。

DX-M1M モジュールでは m1 の代わりに m1m を使用します。フォームファクタのディレクトリは、M.2 モジュールでは mdot2、H1 カードでは h1 です。バージョンのディレクトリは、使用する DX-RT に対応するものを選択してください（DX-RT v3.5.0 → 2.7.6）。上記のとおり、dxrt.service を停止した状態で更新を実行します。問題が発生した場合の確認項目は、Basic → Step 0 トラブルシューティングを参照してください。

Với module DX-M1M, dùng m1m thay cho m1; thư mục form factor là mdot2 cho module M.2 và h1 cho card H1. Chọn thư mục phiên bản phù hợp với DX-RT của bạn (DX-RT v3.5.0 → 2.7.6).
