Pick a method with the tabs below and every command on this page switches to match. Use DX-AllSuite when you want one repository and one installer; use individual install when you only need a single component, or prefer pip and apt packages.

아래 탭에서 방식을 선택하면 이 페이지의 모든 명령이 해당 방식으로 바뀝니다. 저장소 하나로 한 번에 설치하려면 DX-AllSuite를, 특정 컴포넌트만 필요하거나 pip·apt 패키지를 선호한다면 개별 설치를 사용하세요.

在下方标签中选择安装方式，本页所有命令会随之切换。若希望用一个仓库、一个安装脚本搞定，请选 DX-AllSuite；若只需要某一个组件，或更习惯使用 pip 与 apt 软件包，请选单独安装。

下のタブで方式を選ぶと、このページのすべてのコマンドがその方式に切り替わります。1 つのリポジトリとインストーラーでまとめたい場合は DX-AllSuite を、特定のコンポーネントだけが必要な場合や pip・apt パッケージを好む場合は個別インストールを使用してください。

Chọn phương thức bằng các tab bên dưới, mọi lệnh trên trang này sẽ tự chuyển theo. Dùng DX-AllSuite khi bạn muốn một repository và một trình cài đặt duy nhất; dùng cài đặt riêng lẻ khi chỉ cần một thành phần, hoặc khi bạn thích các gói pip và apt hơn.

Install these in the order shown — each step depends on the one before it. DX-RT comes before the firmware step because dxcli, the tool that flashes the firmware, ships with DX-RT.

아래 순서대로 설치하세요. 각 단계는 앞 단계에 의존합니다. 펌웨어를 기록하는 도구인 dxcli가 DX-RT에 포함되어 있으므로, DX-RT를 펌웨어 단계보다 먼저 설치합니다.

请按下面的顺序安装——每一步都依赖于前一步。由于用于烧写固件的工具 dxcli 随 DX-RT 一起提供，因此 DX-RT 要排在固件步骤之前。

以下の順序でインストールしてください。各ステップは前のステップに依存します。ファームウェアを書き込むツールである dxcli は DX-RT に含まれているため、DX-RT をファームウェアの手順より先にインストールします。

Hãy cài theo đúng thứ tự bên dưới — mỗi bước phụ thuộc vào bước trước. DX-RT đứng trước bước firmware vì dxcli, công cụ nạp firmware, đi kèm với DX-RT.

One command installs steps 2–6 at once:

명령 한 번으로 2~6번을 한꺼번에 설치합니다:

一条命令即可一次性安装第 2~6 步：

コマンド 1 回で 2〜6 をまとめてインストールします：

Một lệnh duy nhất cài luôn các bước 2–6:

cd dx-all-suite/dx-runtime
./install.sh --all

To install just one of them, use --target as shown in each step below.

그중 하나만 설치하려면 아래 각 단계의 --target 옵션을 사용하세요.

若只想安装其中某一项，请使用下面各步骤中的 --target 选项。

そのうち 1 つだけをインストールする場合は、下記の各手順にある --target オプションを使用してください。

Để chỉ cài một trong số đó, dùng tùy chọn --target như trong từng bước bên dưới.

APT setup — run once APT 사전 설정 — 최초 1회만 APT 前置设置 — 仅需执行一次 APT 事前設定 — 初回のみ Thiết lập APT — chỉ chạy một lần

Steps 2 and 3 install from the DEEPX APT repository. Register it once before you run any apt install below.

2번과 3번은 DEEPX APT 저장소에서 설치합니다. 아래의 apt install을 실행하기 전에 저장소를 한 번만 등록하세요.

第 2 步和第 3 步从 DEEPX APT 仓库安装。在执行下面任何 apt install 之前，请先注册一次该仓库。

手順 2 と 3 は DEEPX の APT リポジトリからインストールします。下記の apt install を実行する前に、一度だけリポジトリを登録してください。

Bước 2 và 3 cài từ APT repository của DEEPX. Hãy đăng ký nó một lần trước khi chạy bất kỳ lệnh apt install nào bên dưới.

wget -O - https://apt.releases.deepx.ai/gpg | sudo gpg --dearmor -o /usr/share/keyrings/deepx-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/deepx-archive-keyring.gpg] https://apt.releases.deepx.ai $(grep -oP '(?<=UBUNTU_CODENAME=).*' /etc/os-release || lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/deepx.list
sudo apt update

4. NPU F/W

The firmware running on the NPU module itself. Outdated firmware is a known cause of API compatibility problems — DX-RT v3.4.x expects NPU FW v2.7.4 or newer.

NPU 모듈 자체에서 동작하는 펌웨어입니다. 오래된 펌웨어는 API 호환성 문제의 알려진 원인이며, DX-RT v3.4.x는 NPU FW v2.7.4 이상을 요구합니다.

运行在 NPU 模块本身上的固件。过旧的固件是导致 API 兼容性问题的已知原因——DX-RT v3.4.x 需要 NPU FW v2.7.4 或更高版本。

NPU モジュール自体で動作するファームウェアです。古いファームウェアは API 互換性の問題を引き起こす既知の原因であり、DX-RT v3.4.x は NPU FW v2.7.4 以降を必要とします。

Firmware chạy trên chính module NPU. Firmware cũ là nguyên nhân đã biết gây ra vấn đề tương thích API — DX-RT v3.4.x cần NPU FW v2.7.4 trở lên.

cd dx-all-suite/dx-runtime
./install.sh --target=dx_fw
git clone https://github.com/DEEPX-AI/dx_fw

# path layout: dx_fw/<chip>/<fw version>/<form factor>/fw.bin
dxcli -u dx_fw/m1/2.7.4/mdot2/fw.bin

Replace m1 with m1m for a DX-M1M module, and pick the version directory that matches your DX-RT. Run this with dxrt.service stopped — see Basic → Step 0 troubleshooting for the full stop/upgrade/start sequence.

DX-M1M 모듈은 m1 대신 m1m 경로를 사용하며, 버전 디렉터리는 사용 중인 DX-RT에 맞는 것을 선택하세요. dxrt.service를 정지한 상태에서 실행하세요. 정지·업그레이드·재시작 전체 절차는 Basic → Step 0 문제 해결을 참고하세요.

DX-M1M 模块请将 m1 换成 m1m，并选择与您的 DX-RT 匹配的版本目录。请在 dxrt.service 已停止的状态下执行——完整的停止/升级/启动流程请参阅 Basic → Step 0 故障排查。

DX-M1M モジュールでは m1 の代わりに m1m のパスを使用し、バージョンのディレクトリはお使いの DX-RT に対応するものを選んでください。dxrt.service を停止した状態で実行してください。停止・アップグレード・再起動の全手順は Basic → Step 0 トラブルシューティングを参照してください。

Với module DX-M1M, hãy thay m1 bằng m1m, và chọn thư mục phiên bản khớp với DX-RT của bạn. Hãy chạy khi dxrt.service đã dừng — xem Basic → Step 0 xử lý sự cố để biết toàn bộ trình tự dừng/nâng cấp/khởi động lại.

Run dxcli -s and check that your device is listed. Basic → Step 0 shows the full expected output, and its troubleshooting section walks through what to check when nothing appears.

dxcli -s를 실행해 디바이스가 표시되는지 확인하세요. Basic → Step 0에 전체 예상 출력이 있으며, 아무것도 보이지 않을 때 확인할 항목은 문제 해결 섹션에 정리되어 있습니다.

执行 dxcli -s 并确认设备已被列出。Basic → Step 0 给出了完整的预期输出，其故障排查部分说明了什么都没显示时应逐项检查的内容。

dxcli -s を実行し、デバイスが表示されることを確認してください。Basic → Step 0 に期待される出力の全体があり、何も表示されない場合の確認手順はトラブルシューティングの節にまとめられています。

Chạy dxcli -s và kiểm tra thiết bị của bạn có được liệt kê không. Basic → Step 0 cho biết output đầy đủ mong đợi, và phần xử lý sự cố ở đó hướng dẫn cần kiểm tra những gì khi không có gì hiện ra.

dxcli -s
