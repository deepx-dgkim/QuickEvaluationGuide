DEEPX NPU Performance Evaluation Guide

DEEPX NPU 성능 평가 가이드

DEEPX NPU 性能评估指南

DEEPX NPU パフォーマンス評価ガイド

A hands-on guide to measuring real inference performance on DEEPX NPUs — from downloading a model to reading your first FPS number, all the way to profiling, batch benchmarking, and full end-to-end pipeline testing.

DEEPX NPU의 실제 추론 성능을 직접 측정해보는 실습형 가이드입니다. 모델을 내려받아 첫 FPS 숫자를 확인하는 것부터, 프로파일링과 배치 벤치마크, 전체 E2E 파이프라인 테스트까지 다룹니다.

本指南通过实际操作，演示如何测量 DEEPX NPU 的真实推理性能—— 从下载模型、看到第一个 FPS 数值开始，一路涵盖性能剖析（profiling）、 批量基准测试（batch benchmarking），直到完整的端到端（E2E）流水线测试。

DEEPX NPU における実際の推論性能を測定するための実践的なガイドです。 モデルのダウンロードから最初の FPS 値を確認するところに始まり、 プロファイリングやバッチベンチマーク、E2E パイプラインテストまでを扱います。

This guide assumes DX-AllSuite (DX-RT / dx_app / dx_stream) is already installed and your DEEPX NPU (e.g. DX-M1) is recognized by dxcli -s. SDK / driver installation is not covered here — only performance evaluation, once your environment is up and running.

이 가이드는 DX-AllSuite(DX-RT / dx_app / dx_stream)가 이미 설치되어 있고, dxcli -s 명령으로 DEEPX NPU(예: DX-M1)가 정상적으로 인식되는 상태를 전제로 합니다. SDK/드라이버 설치 과정은 다루지 않으며, 환경이 준비된 이후의 성능 평가에만 집중합니다.

本指南假设 DX-AllSuite（DX-RT / dx_app / dx_stream）已经安装完成， 且您的 DEEPX NPU（如 DX-M1）已可通过 dxcli -s 命令正常识别。 SDK/驱动的安装过程不在本指南范围内——仅关注环境就绪之后的性能评估。

本ガイドは、DX-AllSuite（DX-RT / dx_app / dx_stream）がすでにインストールされており、 dxcli -s コマンドで DEEPX NPU（例：DX-M1）が正しく認識されていることを前提としています。 SDK/ドライバのインストール手順はここでは扱いません——環境構築が完了した後の性能評価のみに焦点を当てます。

Basic

Get your first number, fast

가장 빠르게 첫 숫자 확인하기

快速获得第一个数值

最速で最初の数値を確認する

Download a model, run one dxrun command to see maximum throughput, and launch a ready-made dx_app / dx_stream demo to watch real-time FPS. No profiling, no options deep-dive — just results.

모델을 내려받고 dxrun 명령 한 번으로 최대 처리량을 확인한 뒤, 바로 실행 가능한 dx_app / dx_stream 데모로 실시간 FPS를 확인합니다. 프로파일링이나 세부 옵션 없이 결과 확인에만 집중합니다.

下载一个模型，运行一次 dxrun 命令即可查看最大吞吐量， 再启动现成的 dx_app / dx_stream 演示程序 查看实时 FPS。无需性能剖析，也无需深入了解各项选项——只看结果。

モデルをダウンロードし、dxrun コマンドを一度実行するだけで 最大スループットを確認できます。さらに、すぐに使える dx_app / dx_stream のデモを起動してリアルタイム FPS を確認します。 プロファイリングやオプションの深掘りは不要——結果だけを見ます。

What you'll measure

您将测量什么

何を測定するか

LayerToolQuestion it answers 계층도구확인할 수 있는 질문 层级工具可以回答的问题 レイヤーツール確認できる質問
Model-leveldxrun How fast can this one .dxnn model run on the NPU alone (throughput / latency)?
모델 레벨dxrun 이 .dxnn 모델 하나가 NPU에서 단독으로 얼마나 빠르게 동작하는가(처리량/지연시간)?
模型级别dxrun 这一个 .dxnn 模型单独在 NPU 上能跑多快（吞吐量/延迟）？
モデルレベルdxrun この .dxnn モデル単体で NPU 上でどれだけ速く動作するか（スループット/レイテンシ）?
Model-level (batch)dxbenchmark How do many models compare, all at once, with a shareable HTML report?
모델 레벨 (일괄)dxbenchmark 여러 모델을 한 번에 비교하고, 공유 가능한 HTML 리포트로 남기려면?
模型级别（批量）dxbenchmark 如何一次性比较多个模型，并生成可分享的 HTML 报告？
モデルレベル（バッチ）dxbenchmark 複数のモデルを一度に比較し、共有可能な HTML レポートとして残すには?
Application E2Edx_app What FPS do I get with real pre/post-processing (OpenCV-based) around the model?
애플리케이션 E2Edx_app 모델 앞뒤에 실제 전/후처리(OpenCV 기반)를 붙이면 FPS가 얼마나 나오는가?
应用程序 E2Edx_app 在模型前后加入真实的前/后处理（基于 OpenCV）后，能获得多少 FPS？
アプリケーション E2Edx_app モデルの前後に実際の前処理/後処理（OpenCV ベース）を付けると FPS はどうなるか?
Pipeline E2Edx_stream What FPS do I get in a real GStreamer video pipeline (decode → infer → OSD)?
파이프라인 E2Edx_stream 실제 GStreamer 비디오 파이프라인(디코드 → 추론 → OSD)에서는 FPS가 얼마나 나오는가?
流水线 E2Edx_stream 在真实的 GStreamer 视频流水线（解码 → 推理 → OSD）中能获得多少 FPS？
パイプライン E2Edx_stream 実際の GStreamer ビデオパイプライン（デコード → 推論 → OSD）では FPS はどうなるか?
