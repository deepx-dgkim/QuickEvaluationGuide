Performance Evaluation and Benchmarking with DEEPX NPU

使用 DEEPX NPU 进行性能评估与基准测试

DEEPX NPU による性能評価とベンチマーク

Đánh giá hiệu năng và benchmarking với DEEPX NPU

A hands-on guide to evaluating inference performance on DEEPX NPUs — from downloading a model to reading your first FPS number, all the way to profiling, multi-model benchmarking, and full end-to-end pipeline testing.

DEEPX NPU의 추론 성능을 직접 평가하는 실습 가이드입니다. 모델 다운로드와 첫 FPS 확인부터 프로파일링, multi-model 벤치마크, 전체 E2E 파이프라인 테스트까지 다룹니다.

本指南通过实际操作，介绍如何评估 DEEPX NPU 的推理性能：从下载模型、读出第一个 FPS 数值开始，到性能剖析、多模型基准测试，以及完整的 E2E 流水线测试。

DEEPX NPU の推論性能を評価するための実践ガイドです。 モデルのダウンロードから最初の FPS 値の確認、さらにプロファイリング、 マルチモデルベンチマーク、E2E パイプラインテストまでを扱います。

Hướng dẫn thực hành đánh giá hiệu năng inference trên DEEPX NPU: từ tải model và đọc con số FPS đầu tiên đến profiling, benchmark nhiều model và kiểm thử toàn bộ pipeline E2E.

This guide assumes DX-AllSuite (DX-RT / dx_app / dx_stream) is already installed and your DEEPX NPU (e.g. DX-M1) is recognized by dxcli -s. SDK / driver installation is not the main focus here — the setup guide has a condensed walkthrough. This guide covers performance evaluation once your environment is up and running.

이 가이드는 DX-AllSuite(DX-RT / dx_app / dx_stream)가 이미 설치되어 있고, dxcli -s 명령으로 DEEPX NPU(예: DX-M1)가 정상적으로 인식되는 상태를 전제로 합니다. SDK/드라이버 설치는 이 가이드의 주된 내용이 아니며, 요약된 절차는 설치 가이드에 있습니다. 이 가이드는 환경이 준비된 이후의 성능 평가를 다룹니다.

本指南假定 DX-AllSuite（DX-RT / dx_app / dx_stream）已安装，且 dxcli -s 能识别 DEEPX NPU（如 DX-M1）。SDK/驱动的安装不是本指南的重点，简要步骤请参阅安装指南。本指南介绍环境就绪后的性能评估。

本ガイドは、DX-AllSuite（DX-RT / dx_app / dx_stream）がインストール済みで、 DEEPX NPU（例：DX-M1）が dxcli -s で認識されていることを前提としています。 SDK/ドライバのインストールは本ガイドの主な対象ではありません。手順の概要はセットアップガイドを参照してください。 本ガイドでは、環境構築が完了した後の性能評価を扱います。

Hướng dẫn này giả định DX-AllSuite (DX-RT / dx_app / dx_stream) đã được cài đặt sẵn và DEEPX NPU (ví dụ DX-M1) đã được dxcli -s nhận diện. Việc cài đặt SDK / driver không phải trọng tâm của tài liệu này; hướng dẫn cài đặt có tóm tắt các bước. Tài liệu này tập trung vào đánh giá hiệu năng khi môi trường đã sẵn sàng.

This guide was written and validated against DX-AllSuite v2.5.0 (DX-RT v3.5.0, NPU driver v2.7.0, NPU FW v2.7.6, dx_app v3.3.0, dx_stream v3.2.0, DX-COM v2.5.0). Starting with DX-RT v3.5.0 the runtime reads the latest Model Zoo .dxnn files (format v9) and requires driver v2.7.0 / FW v2.7.6 or newer. Command syntax and output should be broadly similar on other versions, but exact version strings, options, or behavior may differ.

이 가이드는 DX-AllSuite v2.5.0(DX-RT v3.5.0, NPU 드라이버 v2.7.0, NPU FW v2.7.6, dx_app v3.3.0, dx_stream v3.2.0, DX-COM v2.5.0)을 기준으로 작성하고 검증했습니다. DX-RT v3.5.0부터 Model Zoo의 최신 .dxnn(포맷 v9)을 읽을 수 있으며, 드라이버 v2.7.0 / FW v2.7.6 이상이 필요합니다. 다른 버전에서도 명령어 구문과 출력은 대체로 비슷하지만, 정확한 버전 문자열, 옵션, 동작은 다를 수 있습니다.

本指南基于 DX-AllSuite v2.5.0（DX-RT v3.5.0、NPU 驱动 v2.7.0、NPU FW v2.7.6、dx_app v3.3.0、dx_stream v3.2.0、DX-COM v2.5.0）编写并验证。自 DX-RT v3.5.0 起，运行时可读取最新 Model Zoo 的 .dxnn 文件（格式 v9），并要求驱动 v2.7.0 / FW v2.7.6 或更高版本。在其他版本上，命令语法和输出大体相同，但具体的版本字符串、选项或行为可能不同。

本ガイドは DX-AllSuite v2.5.0（DX-RT v3.5.0、NPU ドライバ v2.7.0、NPU FW v2.7.6、 dx_app v3.3.0、dx_stream v3.2.0、DX-COM v2.5.0）で作成・検証しています。DX-RT v3.5.0 以降のランタイムは Model Zoo の最新 .dxnn ファイル（フォーマット v9）に対応し、ドライバ v2.7.0 / FW v2.7.6 以降を必要とします。 他のバージョンでもコマンドの構文や出力はおおむね同じですが、具体的なバージョン文字列、オプション、動作は異なる場合があります。

Hướng dẫn này được viết và kiểm chứng trên DX-AllSuite v2.5.0 (DX-RT v3.5.0, NPU driver v2.7.0, NPU FW v2.7.6, dx_app v3.3.0, dx_stream v3.2.0, DX-COM v2.5.0). Từ DX-RT v3.5.0, runtime đọc được các file .dxnn mới nhất của Model Zoo (định dạng v9) và yêu cầu driver v2.7.0 / FW v2.7.6 trở lên. Cú pháp lệnh và output trên các phiên bản khác nhìn chung tương tự, nhưng chuỗi phiên bản, tùy chọn hoặc hành vi cụ thể có thể khác.

Nhanh chóng có kết quả đầu tiên

Download a model, run one dxrun command to see maximum throughput, and launch a ready-made dx_app / dx_stream demo to watch real-time FPS. No profiling, no options deep-dive — just results.

모델을 내려받고 dxrun 명령 한 번으로 최대 처리량을 확인한 뒤, 바로 실행 가능한 dx_app / dx_stream 데모로 실시간 FPS를 확인합니다. 프로파일링이나 세부 옵션 없이 결과 확인에만 집중합니다.

下载模型，运行一条 dxrun 命令查看最大吞吐量，再启动现成的 dx_app / dx_stream 演示，观察实时 FPS。不做性能剖析，也不深入讲解选项，只看结果。

モデルをダウンロードし、dxrun コマンドを 1 回実行して最大スループットを確認したあと、 用意済みの dx_app / dx_stream デモを起動してリアルタイム FPS を確認します。 プロファイリングやオプションの詳細は省き、結果だけに絞ります。

Tải model, chạy một lệnh dxrun để xem throughput tối đa, rồi chạy demo dx_app / dx_stream có sẵn để xem FPS theo thời gian thực. Không cần profiling hay tìm hiểu chi tiết tùy chọn, chỉ tập trung vào kết quả.
